It will CrashLoopBackOff until every provider's credentials secret exists in
{{ .Release.Namespace }}. Each key in those secrets becomes an env var.

Provider settings are passed through untouched, so this chart cannot tell you a
required one is missing — the operator does, at startup, naming the key. If the
pod restarts immediately after this install, read its log first:
  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "external-node-autoscaler.fullname" . }}

Keys and defaults for each provider live with the code that reads them:
{{- range .Values.providers }}
  src/autoscaler/providers/{{ .name }}/
{{- end }}

Nothing rented ever calls this cluster: the operator generates each machine's
certificate authorities before ordering it and assembles the kubeconfig itself.
There is no join token and no k3s-kubeconfig secret.
